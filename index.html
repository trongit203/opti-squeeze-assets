How it works

Three steps, no sign-up.

1

Pick a tool and your files

Open the Tool Hub, choose what you need — Compress, Merge, Resize, Convert, and 17 more — then select your photos or PDFs.

2

Set the options

Quality preset for compression, page range for split/extract, target format for convert — whatever that tool needs.

3

Run & save

OptiSqueeze processes each file on-device and saves the result to Downloads/OptiSqueeze, or replaces the original in place.

Quality presets

One knob, tuned for different needs — used by Compress and everywhere else quality matters.

Maximum

Smallest possible file size. Best when storage or upload limits matter more than fine detail.

Balanced

The default — a solid size reduction while keeping images and documents looking sharp.

Lossless

Trims file size with no visible quality loss, for when the original look has to stay intact.
